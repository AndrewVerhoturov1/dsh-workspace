# POSTMAN TASK

user_intent:
Создай в корне репозитория один файл postman-check.html — маленькую самодостаточную HTML-страницу «Проверка Postman». В одном файле без библиотек, зависимостей и сборки должны быть: заголовок, кнопка «Нажми меня» и текстовый элемент. После нажатия на кнопку текст на странице должен измениться ровно на «Postman работает». Используй встроенные HTML/CSS/JavaScript, аккуратную простую вёрстку и доступные подписи. Не изменяй другие файлы.
