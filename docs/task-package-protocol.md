# Task Package Protocol

## Формат

Один файл задачи:

REQ_<timestamp>_<digits>.md

Файл содержит:
- request_id;
- автора создания;
- цель;
- техническое задание;
- ссылки на обязательные документы;
- repository;
- base commit;
- ожидаемый результат;
- проверки.

## Ответ внешнему агенту

Внешний prompt содержит только:
1. request_id;
2. ссылку на общий skill repository;
3. ссылку на task-файл.

Не копировать техническое задание в prompt.
