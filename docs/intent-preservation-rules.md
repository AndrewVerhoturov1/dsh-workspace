# Правила сохранения намерения

## Обязанности локального агента (Л1)

Л1:

- задаёт уточняющие вопросы, когда без них нельзя точно понять запрос;
- записывает только ответы и требования, подтверждённые пользователем;
- создаёт task-файл для внешнего агента.

Л1 не:

- проектирует решение вместо внешнего агента;
- добавляет требования, ограничения или критерии, которых пользователь не подтверждал;
- меняет смысл пользовательского запроса.

## Обязанности внешнего агента

Внешний агент анализирует задачу, выбирает решение и реализует его в пределах
подтверждённого task-файла.

## Формат данных

- `user_intent` содержит исходное намерение пользователя;
- `confirmed_requirements` содержит только подтверждённые требования;
- `clarifications` содержит вопросы и ответы либо сведения, которые ещё нужно
  уточнить;
- `constraints` содержит только явно заданные ограничения.

Пустые `clarifications` и `constraints` означают, что такие сведения не были
переданы. Локальный код не заполняет их догадками.
