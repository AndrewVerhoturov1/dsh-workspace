# Проверка полноты общих правил

Общие правила должны покрывать:

- идентичность запроса;
- границы памяти;
- работу с GitHub;
- правила чтения документов;
- порядок выполнения задач;
- ограничения на изменения;
- формат отчета;
- работу с артефактами;
- обработку ошибок.

Если правило относится только к конкретной задаче, оно должно находиться в task-файле.
