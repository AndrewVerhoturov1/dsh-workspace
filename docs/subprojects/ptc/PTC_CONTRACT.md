# Контракт самостоятельного ПТС-ядра v1

## Область и API

`plugins/dsh-ptc` — отключённый самостоятельный пакет. Экспорт: `validatePtcProfile(input)` (возвращает глубоко ограниченный неизменяемый снимок или бросает `TypeError`), `DEFAULT_LIMITS`, `MAX_LIMITS` и `createPtcRuntime()`. Runtime предоставляет `run({program, language='javascript', profile, bindings, signal})` и идемпотентный `dispose()`. Ошибки допуска и исполнения выражаются объектом результата, а не повтором программы. Каждая программа — новый процесс, новый QuickJS runtime/context. Нет persistent REPL, восстановления, повтора и edit-run. Импорт без побочных эффектов.

`bindings` — собственные свойства простого объекта, имена из проверенного `profile.tools`. Для каждого имени обязательно наличие собственной функции; лишние функции не передаются ребёнку. Таблица функций и профиль снимаются в копию до запуска. Функция получает ровно один JSON-аргумент и `{signal,runId,callId}`; `signal` — сигнал данного запуска, который прерывается при завершении. Нет глобального реестра функций и выбора Agent по модельному `agentId`. Интеграция этапа 2 обязана построить разрешённую таблицу из фактического Agent и проводить каждый вызов через штатный диспетчер Harness с исходной идентичностью и проверками. Само ядро этих полномочий не подтверждает.

## Профиль v1

Чистый JSON с ровно пятью ключами: `schemaVersion:1`, `id` (ASCII буква/цифры/дефис, до 64), `revision` (1…1000000), `tools` (до 64 имён, включая пустой массив), `limits` (ровно все перечисленные ниже поля). Имя функции: `[A-Za-z_][A-Za-z0-9_]*`, до 64 символов; дубли, wildcard, `__proto__`, `prototype`, `constructor` запрещены. Размер канонической JSON-копии профиля ≤8192 байт. Неправильные типы, лишние/отсутствующие поля, NaN/Infinity/строковые числа и значения вне диапазона отвергаются. Профиль не содержит код, роль, системный промпт, модули, исполняемый путь, окружение или навыки.

Значения по умолчанию относятся к лабораторному стенду, не обоснованы как production-пределы агентных сетевых функций. Числа — безопасные целые; минимум в таблице, максимум сервисного владельца и значение примера:

| Поле | Единица | Мин | Пример | Макс |
|---|---:|---:|---:|---:|
| maxProgramBytes | UTF-8 байт | 1 | 262144 | 262144 |
| maxWallMs | мс календарного времени | 100 | 10000 | 30000 |
| quickjsMemoryBytes | байт QuickJS heap | 8388608 | 33554432 | 67108864 |
| maxStackBytes | байт QuickJS stack | 65536 | 524288 | 1048576 |
| maxToolCalls | вызовов | 0 | 64 | 256 |
| maxConcurrentToolCalls | вызовов | 0 | 4 | 8 |
| maxQueuedToolCalls | вызовов | 0 | 16 | 32 |
| maxMessageBytes | байт полезного JSON-кадра | 1024 | 1048576 | 1048576 |
| maxTotalBridgeBytes | байт обоих направлений с заголовками | 2048 | 8388608 | 16777216 |
| maxOutputBytes | байт результата и логов отдельно | 0 | 65536 | 65536 |
| maxLogEntries | записей | 0 | 256 | 256 |
| maxValueDepth | уровней JSON | 1 | 32 | 32 |
| maxValueNodes | узлов JSON | 1 | 10000 | 10000 |

Нуль разрешён только как отсутствие функций, очереди, логов или вывода. Параллельность ≤ общего числа вызовов; при разрешённых вызовах она положительная; очередь ≤ общего числа. Вывод+2048 ≤ кадра, программа+8192 ≤ кадра, кадр+4 ≤ бюджета. Значения за пределом не повышаются автоматически. На runtime одновременно максимум два процесса, без очереди запусков; старт ≤3 с (или меньший срок профиля), подтверждение остановки: мягкая остановка ≤750 мс, затем принудительная ≤750 мс. Неразрешённые Host Promise ограничены 64 на экземпляр сервиса, включая результаты завершённых запусков.

## Язык и граница исполнения

`javascript` по умолчанию — тело асинхронной функции с `await` и явным `return` JSON. `typescript` — только удаляемые аннотации через Node `stripTypeScriptTypes({mode:'strip'})` внутри дочернего процесса; синтаксис, требующий трансформации, не поддержан. Экспорт и модули не поддержаны. Диагностика в файле `ptc-program.js` смещена на строку обёртки (исходная строка программы +1); TypeScript wrapper также прибавляет строку. `undefined` не JSON и даёт `invalid-output`, `null` допустим.

Ребёнок — фиксированный Node entry `src/executor.mjs`, запущенный без shell, без наследования Node execArgv и с минимальным окружением, cwd — отдельный временный каталог. В QuickJS нет Host `process`, `require`, `fetch`, сети, файлов, Node-таймеров, std/os и загрузчика модулей. Доступны стандартные вычисления JS, `tools.<имя>(json)` и ограниченный `console`. `Function` внутри QuickJS не переводит вычисление в Node. QuickJS-движок закреплён `0.32.0`; обычные функции возвращают QuickJS Promise, `executePendingJobs()` обслуживает очередь, Asyncify не используется.

## Протокол и завершение

Один запуск — один `runId`, числовые последовательные `callId`. Версия `v:1`; кадр — 4-байтовая big-endian длина, затем UTF-8 JSON. Сообщения: parent `start` → child `ready` → `call` / parent `reply` / `log` → child `done`. Принимающая сторона проверяет размер до JSON.parse, UTF-8, версию, направление, ID, поля, порядок и общий бюджет. Сторонний/повторный вызов отвергается до Host-функции; собственные права повторно проверяются на каждом `call`. Обратное давление учитывается записью с callback; совокупный бюджет включает кадры обоих направлений. `stderr` имеет отдельный предел 4096 байт. Служебный отказ при переполнении канала может завершиться закрытием без терминального кадра; родитель сохраняет свою первичную причину.

Данные — только JSON с ограничением байт, глубины, узлов; нет BigInt, undefined, функций, циклов, getters/toJSON, специальных объектов, опасных ключей и молчаливого преобразования нечисловых чисел. Родитель сериализует копию без исполнения пользовательских getters; гость передаёт проверенное значение через приватный сериализатор QuickJS и родитель проверяет его снова. Логи — массив JSON-строк, не бесконтрольный вывод в stdout.

Результат `{status, value?, error?, logs, effects, cleanupError?}`. Статусы v1: `ok`, `invalid-input`, `syntax-error`, `runtime-error`, `invalid-output`, `protocol-error`, `limit-exceeded` (код поля), `cancelled`, `process-error`, `cleanup-error`, `unawaited-calls`. Это локальные статусы ядра, не Postman. `effects` — фактический снимок принятых вызовов с `completed`, `failed`, `pending`. Ошибка после выполненной функции не откатывает её эффект. Результат программы с незавершённым callback — `unawaited-calls`, не полный успех.

Отмена до старта не создаёт процесса. Внешний календарный таймер охватывает всё, включая TypeScript; QuickJS interrupt — вспомогателен. Abort/dispose закрывает новые вызовы, отменяет сигнал начатых, не ожидает некооперативные Promise бесконечно, завершает ребёнка и сохраняет снимок эффектов. Поздние отклонения обрабатываются, но не доставляются повторно. Повторный запуск не повторяет уже выполненные функции. `kill()` не является подтверждением выхода — ожидается событие `close`; при недоказанной остановке `cleanupError` и занятый слот сохраняются, а успех не объявляется. При аварии самого родителя эта гарантия не распространяется на Host-вызовы и дочерний процесс. Синхронный блокирующий доверенный callback остаётся блокирующим на основном потоке.

## Пределы защиты и среда

QuickJS ограничивает полномочия программы, отдельный процесс ограничивает последствия сбоя исполнителя. Это не доказанный OS sandbox: нет отдельного пользователя, контейнера или защиты от уязвимости QuickJS/Node. Предел памяти QuickJS/WASM не является строгим пределом всего процесса ОС/V8. Тесты на пользовательской Windows подтверждают функциональность и ограниченные превышения, но не доказывают containment произвольного native exploit. При запуске из установленной копии требуются все пакетные `src/` и транзитивный WASM из lockfile. Сетевой загрузки при `run()` нет.
