# Журнал ПТС

## 2026-09-29 — Исправления после проверки PR №245

Обрыв дочернего pipe обрабатывается на самих потоках и завершает запуск без падения родителя; ожидающие записи отклоняются. Бюджет ответа Host-функции теперь терминален, служебная оболочка отделена от лимита JSON-значения профиля. Снимок эффектов различает не начатые и незавершённые функции, учитывает завершения во время очистки; повторный `dispose` ждёт то же завершение. Ошибка очистки исключает `ok`. Добавлены адресные регрессионные сценарии; на Windows / Node v24.21.0 пакетные тесты 30/30 и проверка установленного архива с QuickJS/WASM прошли.
