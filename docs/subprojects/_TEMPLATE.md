# Шаблон подпроекта DSH

Создайте папку `docs/subprojects/<id>/` и два файла ниже. Удалите подсказки в угловых скобках.

## SUBPROJECT.md

```markdown
# <Название подпроекта>

id: <kebab-case-id>
status: <active|planned|paused|completed|archived>
updated: <YYYY-MM-DD>

## Goal

<Какой долговременный результат должен дать подпроект.>

## Current focus

<Что считается текущим состоянием и на чём сосредоточена работа сейчас.>

## Next step

<Один наиболее конкретный следующий шаг.>

## Boundaries

- <Что нельзя менять или расширять без отдельного решения.>
- <Какие глобальные/подсистемные правила особенно важны.>

## Read first

1. `AGENTS.md`
2. `REPO_POLICY.md`
3. <канонический workflow/contract затронутой подсистемы>
4. <остальные действительно необходимые документы>

## Main paths

- `<основной путь>`
- `<основной путь>`

## Current decisions

- <Уже принятое решение, которое не нужно заново обсуждать в каждой задаче.>
- <Ещё одно существенное решение.>
```

## JOURNAL.md

```markdown
# Журнал подпроекта <Название>

## Правила

- Записывать только существенные решения и этапы.
- Не вести журнал каждого commit, теста или микрошагa.
- Каждая запись кратко отвечает: что изменилось, почему, результат.

## Записи

### <YYYY-MM-DD> — <короткое название>

- **Что изменилось:** <...>
- **Почему:** <...>
- **Результат:** <...>
```

После создания добавьте подпроект одной строкой в таблицу `docs/subprojects/INDEX.md`.
