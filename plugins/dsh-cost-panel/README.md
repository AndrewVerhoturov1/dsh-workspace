# Панель расходов DSH

Отдельный плагин для DSH 0.1.1-rc.2. Панель во всех открытых чатах размещается в штатном `conversation.composer.dock` перед старой строкой статистики; старая строка не заменяется и не изменяется. Иконки и компактные подсказки взяты из согласованного `design/token-cost-panel.html` (не из PNG).

## Учёт

Штатный `llm/stream` — одна попытка вызова модели, включая неудачные/повторные попытки и auxiliary compaction/session-title, когда вызов привязан к сессии. Вызовы без sessionId не приписываются случайному чату. Целые снимки `cost-panel/attempt` добавляются в существующий append-only журнал сессии, без второго хранилища. ID одной попытки отличает её от других вызовов в том же шаге; финальные сообщения/usage chunks того же шага не добавляются повторно. История до подключения читается из существующих assistant/chunk, assistant/message и llm/retry. Повторы до подключения observer сохраняют тот же turn/step, поэтому их usage нельзя точно разделить по попыткам: такие llm/retry делают число вызовов и стоимость неизвестными, а не точным итогом одного шага. Исторические compaction/start без записанного usage делают итог неизвестным: потерянные сведения не восстанавливаются выдуманными числами.

Текущий агент — только собственные события выбранной сессии после durable seedLength. Команда — корень делегирования и все уникальные descendants с origin=subagent, включая сохранённых/нерезидентных детей. Обычный fork начинает собственную команду и не тянет стоимость старого предка. Открытие дочернего чата не меняет командный итог. Чтение идёт через существующие sessions/sessionPersistence, без запуска детей.

input/cacheRead/cacheWrite/output — непересекающиеся категории DSH. reasoning входит в output и оценивается для подсказки отдельно, но никогда не прибавляется к итогу повторно. Отсутствующий счётчик/тариф отличается от подтверждённого 0: показывается «—» / «неизвестна». Если любой оплачиваемый компонент неизвестен, итог не выдаётся за полный. При отсутствии persistence полнота сохранённой команды неизвестна.

## Цены

`model-prices.json` — обычный редактируемый вручную JSON, USD/1M токенов. checkedDate и sourceUrls фиксируют проверку официальных страниц; обновляйте этот файл периодически и сверяйте условия. Значения взяты из отдельно проверенного исследования от 2026-10-10. Только точное совпадение publicId: внутренние псевдонимы не угадываются. Оценка по стандартным ценам API, не сумма подписочного счёта ChatGPT/Codex.

Порог выбирается для всего вызова по input+cacheRead+cacheWrite; все его токены получают соответствующий тариф. Для Anthropic отсутствие фактического TTL split записи кэша не означает 5m: стоимость компонента неизвестна. Нормализованный DSH TokenUsage не сохраняет TTL split; если поставщик действительно передаёт cacheWrite5mTokens/cacheWrite1hTokens и их сумма совпадает с cacheWriteTokens, используются соответствующие ставки. Выход уже содержит рассуждения.

## Подключение

Пакет не требует нового сборщика: `client.js` — готовая нативная factory-запись DSH ModuleLoader с React действующего shell; Host — ESM. `npm run build` проверяет синтаксис, `npm test` выполняет целевые проверки.

В действующем профиле Web подключить пакет штатно:

    dsh plugin --profile web add <absolute-path-to-plugins/dsh-cost-panel>

CLI должен добавить зависимость и bundle из cordis.patch.yml; сохраняйте остальные зависимости/config. Новый состав client-plugin активируется при перезапуске того же DSH Host и обновлении его исходного GUI URL. Не запускайте заменяющий Vite/server; shell требует DSH BOOT. Не останавливайте Host с активными заданиями: безопасное окно перезапуска согласует владелец. Без работающего dev:web watcher не обещается автоматическое HMR.

Живое обновление стоимости использует существующую all-session projection feed и sessions.list subscription, без таймерного опроса или второй SSE/WebSocket. Unary RPC /cost-panel/get ограничен loopback, возвращает только агрегаты, не содержимое чатов/credentials. Запросы объединяются во время чтения, чтобы поток обновлений не отменял каждый расчёт.
