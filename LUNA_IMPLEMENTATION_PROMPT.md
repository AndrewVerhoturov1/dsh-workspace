Внедри WP-009 Agent Task Package Protocol.

Цель:
Добавить слой, где локальная модель создает task-файл для внешнего агента.

Требования:
- один task-файл на одну задачу;
- REQ является ключом корреляции;
- task-файл хранится в GitHub;
- внешний prompt содержит ссылки, а не полный технический текст;
- общий skill repository остается источником постоянных правил.

Не менять WP-002—WP-007 контракты без необходимости.

Проверить:
- UTF-8;
- markdown;
- git diff --check;
- тесты.

Создать PR, merge не выполнять.
