# Приёмка — Carcassonne 3D

Сводка фактических результатов в назначенном task worktree. E2E проверяет действия через UI, но не заменяет GPU/визуальную оценку. Task PR #443 открыт с base `main`; слияние и promotion в `preview` не выполнялись.

## Игровой движок, типы и сборка

- **100 полных партий:** Vitest suite `tests/game-invariants.test.ts` прошёл для seed `AUTONOMOUS_0000`–`AUTONOMOUS_0099`, с чередованием 2–5 участников. Проверялись сохранение/уникальность всех 72 физических ID плиток, уникальность позиций, соседние рёбра с учётом поворота, ссылки фигурок на существующие области, запас 0–7 и его сохранение, конечность очков, воспроизводимость состояния, replay сохранения, завершение не позже 142 принятых команд и отказ от хода без изменения финального состояния.
- **Полный Vitest:** `npm test` — PASS, 5 файлов / 36 тестов, включая 100 автономных партий и прежние тесты движка, сцены и UI. Выведено стороннее предупреждение `THREE_CJS_DEPRECATED`, ошибок тестов нет.
- **TypeScript и production build:** `npm run check` — PASS; `npm run build` — PASS, Vite обработал 600 модулей. Выведено предупреждение о чанке JavaScript около 1,270 кБ до gzip (>500 кБ), это не ошибка.
- **Дополнительные regression-проверки сцены:** `src/scene/RUNTIME_FIX_REPORT.md` фиксирует PASS 1 проверки SceneLabel, 13 тестов сцены/UI, 4 тестов anchorRegression, 2 тестов runtimeRegression, TypeScript и production build на финальных релевантных входах. Это адресные проверки изменений, не GPU-рендеринг.
- **Каталог:** 24 типа / 72 экземпляра и правила документированы в `RULES_NOTES.md`. Изображения B1 сверены визуально со всеми 24 топологиями. Подробные полевые полупорты/связи полей реконструированы по этим данным и не являются издательской машинно-сертифицированной графовой моделью. Четыре локальных anchor-координаты были уточнены и прошли указанные геометрические регрессионные проверки.

## E2E через реальный UI

Шесть Playwright-сценариев `tests/e2e/game.spec.ts` имеют PASS-свидетельства, собранные совокупно из нескольких адресных прогонов, а не из единого полного прогона всех шести после последних исправлений:

- Тесты 1, 2 и 4 ранее завершились PASS (запуск 2/5 участников и ход, вращение/размещение/фигурка, одинаковая последовательность для одинакового seed).
- Тест 6 прошёл адресно: Tile Lab показывает 24 определения, четыре поворота и проверку соседней пары.
- После test-only исправлений тест 3 прошёл: JSON скачан; повреждённый файл отклонён при сохранении прежних turn/name/heraldry; корректный файл восстановлен.
- После test-only исправлений тест 5 прошёл: партия завершилась UI-командами с законными размещениями и выбором фигурки/пропуском. Время — около 1,3 минуты; предел — 142 цикла и Playwright timeout 180 секунд.
- Display-проверка `tests/e2e/display.spec.ts` прошла отдельно: одна Playwright-проверка, 14,8 с, контекст DPR 2, действующий WebGL и instrumented draw-call buckets во время реального pointer drag/wheel/Fit Board ввода. Сборка Chromium использовала программный SwiftShader; тест не измеряет FPS и не подтверждает физический GPU. Терминальный лог не показывает JSON attachment с точным renderer/buffer/cadence, поэтому конкретные численные FPS/кадры не заявляются.
- Таким образом, все шесть основных game E2E и отдельная display-проверка имеют PASS-свидетельства в адресных запусках, не в одном общем полном прогоне. Воспроизводимые детали, команды и серверные job приведены в [tests/e2e/E2E_FINAL.md](tests/e2e/E2E_FINAL.md) и [tests/e2e/DISPLAY_REPORT.md](tests/e2e/DISPLAY_REPORT.md). Предупреждения Playwright о конфликте `NO_COLOR`/`FORCE_COLOR` не привели к сбоям тестов.

## Визуальные и производительные ограничения

Проверенная display-среда подтвердила WebGL отрисовку и реакцию на камеру при DPR 2 на программном SwiftShader. Это не физический GPU benchmark: 60 FPS, аппаратная производительность и качество изображения на других устройствах не заявляются. Bundle содержит около 1,270 кБ JavaScript до gzip и превышает стандартный порог чанка Vite 500 кБ.
