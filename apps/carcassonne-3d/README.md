# Carcassonne 3D

Самостоятельная локальная hot-seat игра в Каркассон: 2–5 участников, процедурная 3D-доска, управление ходом, подсчёт очков, сохранение партии и лаборатория плиток. Игра не подключается к серверу и не отправляет данные по сети.

## Запуск

Требуется Node.js 24.x. Из этой папки приложения:

```sh
npm ci
npx playwright install chromium
npm run dev -- --port 5188 --strictPort
```

Откройте адрес Vite, указанный в терминале (при параметрах выше — `http://127.0.0.1:5188/`). Для production-сборки и проверок:

```sh
npm run check
npm run build
npm test
npm run test:e2e
```

Playwright запускает Chromium; если браузер ещё не установлен, выполните `npx playwright install chromium`. Шесть E2E-сценариев подтверждены несколькими адресными прогонами; сведения и границы проверки приведены в [ACCEPTANCE.md](ACCEPTANCE.md).

## Партия и управление

1. На стартовом экране выберите от двух до пяти участников, задайте имя, цвет и герб; seed — произвольная непустая строка. Повторное использование seed и тех же ходов даёт воспроизводимую партию. По умолчанию используется `POSTMAN_TEST_0042`.
2. В фазе плитки выберите один из разрешённых ходов на доске или в списке. Поворот — кнопки управления либо клавиши **Q** против часовой стрелки, **E/R** по часовой. Наведите указатель на разрешённую клетку и выберите её.
3. В фазе фигурки выберите доступную область или пропустите ход. Дороги, города, монастыри и поля приносят очки по правилам движка; завершённые объекты возвращают фигурки, фермеры остаются на поле до итогового подсчёта. Игра заканчивается, когда больше нельзя вытянуть размещаемую плитку.
4. Счёт, текущий участник, остаток фигурок и состояние партии показаны на панели. Можно скачать JSON-сохранение и загрузить его обратно; загрузка проверяется проигрыванием команд, ошибочный файл не заменяет текущую партию. Локально доступна функция продолжения сохранённой партии.
5. Камеру можно вращать перетаскиванием, перемещать и масштабировать; «Поле целиком» возвращает обзор. Раздел **«Лаборатория плиток»** показывает каталог, варианты поворота, регионы, поля и соседние плитки; лаборатория не меняет правила партии.

При недоступности WebGL интерфейс предоставляет двумерный режим доски. Проверенная display-проверка подтвердила реальный WebGL-рендеринг и ввод камеры в Chromium при DPR 2 на программном SwiftShader; это не измерение производительности физического GPU и не обещание 60 FPS. Визуальное качество и производительность на целевом устройстве зависят от среды.

## Реализация и художественные материалы

Игровой движок `src/game/` — чистая логика TypeScript: фиксированный каталог base72, генерация по seed, разрешённые размещения и цели фигурок, соединение регионов, подсчёт и версия сохранения. Состояние меняется только через `transition`. Сцена `src/scene/` отображает предоставленные движком варианты, использует процедурную оригинальную графику и передаёт только разрешённые идентификаторы действий. UI `src/ui/` ведёт hot-seat настройки и ход, очки, сохранение и Tile Lab. Камера и лабораторные представления не входят в состояние игры. См. [CONTRACT.md](CONTRACT.md).

Все иллюстрации создаются локально кодом проекта: внешние наборы графики и официальные изображения или брендинг не включены. Состав и видимые топологии всех 24 типов плиток сверялись с изображениями B1 из указанного в `RULES_NOTES.md` правила. Однако подробные полевые полупорты и связи фермерских полей были реконструированы: это визуальная сверка и реконструкция, а не машинная сертификация издателем.

## Ограничения и проверки

Vitest проверяет движок, сцену и интерфейс; в частности, отдельный suite прошёл 100 полных автономных партий на seed `AUTONOMOUS_0000`–`AUTONOMOUS_0099`. Зафиксированный полный `npm test` завершился с 36 тестами в пяти файлах. После изменений сцены адресные исправительные тесты также прошли. Шесть E2E-проверок успешно выполнены совокупно в нескольких прогонах, а не одним полным повторным запуском; детали — в [ACCEPTANCE.md](ACCEPTANCE.md).

Production bundle большой (около 1,27 МБ JavaScript до gzip); Vite сообщает предупреждение о чанке свыше 500 КБ. При сборке также может выводиться стороннее предупреждение Three.js о deprecated CommonJS-импорте. Это предупреждения, не ошибки проверок. Аппаратная производительность и качество изображения на других GPU/устройствах не оценивались.
