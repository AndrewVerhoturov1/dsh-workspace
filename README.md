# WP-009 Agent Task Package Protocol

Цель:
Создать стандарт передачи задачи от локального агента к внешнему агенту.

Главная идея:
Локальная модель создает один технический task-файл, публикует его в GitHub, а внешний чат получает ссылку на правила и ссылку на task.

Основной идентификатор:
REQ_YYYYMMDDTHHMMSSZ_NNNN

REQ используется только как ключ корреляции текущей задачи.
