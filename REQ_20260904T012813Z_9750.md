1. POST-MERGE CLEANUP

- unregister Result Workspace;
- убедиться, что Result Session больше не использует worktree;

  - branch == ожидаемая postman/req-*;

- git worktree prune;
- удалить локальную task branch;
- удалить remote task branch без force;
- git fetch --prune origin;
- записать durable cleanup receipt со статусом CLEANED.

Перед созданием новой Postman task branch/worktree PREPARE должен классифицировать найденные старые postman/req-* ресурсы.

- CLOSED WITHOUT MERGE → BLOCK;
