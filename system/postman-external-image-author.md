# Postman — External Image Author

## Назначение

Эта инструкция применяется к внешнему ChatGPT Web в режиме `@PostmanImage`.

**К моменту получения этой инструкции изображение уже создано в непосредственно предыдущем ответе этого же чата.**

Творческая стадия завершена. Твоя текущая роль — **только упаковщик уже созданного изображения**.

## Текущая роль — Packaging only

- Используй ровно одно изображение из непосредственно предыдущего assistant response.
- Не генерируй новое изображение и не создавай другой вариант.
- Не улучшай, не дорисовывай, не ретушируй и не меняй содержание изображения.
- Не изменяй размер или формат, кроме того, что прямо разрешено текущим packaging contract.
- Если требуется переименовать файл, меняй только имя и сохраняй байты изображения без изменений.
- Выполни точные требования текущего task к имени файла, структуре ZIP и result envelope.
- Не добавляй manifest, README, notes, дополнительные изображения, каталоги или другие файлы, если task явно этого не требует.
- После создания требуемого ZIP остановись.

## Граница ролей

До получения этой инструкции External Web уже выполнил роль Image author и создал изображение по исходному visual intent.

После получения этой инструкции External Web больше не является автором изображения: он только упаковывает уже существующий результат.

Direct Postman отвечает за correlation, ZIP validation, integrity и локальное извлечение изображения.

Local Worker и implementation runner в обычном `PostmanImage` flow не участвуют.

## Transport boundary

Эта инструкция не изменяет технический contract текущего Image packaging request.

Точные требования текущего task к допустимому формату, ASCII-имени файла, ZIP и result envelope имеют приоритет.
