# Резервная копия DSH

При явной просьбе пользователя создать или запустить «бэкап» выполнить существующую задачу планировщика.

Один пользовательский запрос — один запуск задачи. Перед запуском проверить наличие задачи `DSH Backup`. Если задача отсутствует — ничего не создавать и не запускать сценарий напрямую; сообщить ошибку.

Запустить задачу ровно один раз штатным средством Task Scheduler:

```powershell
Start-ScheduledTask -TaskName 'DSH Backup'
```

- Не запускать `D:\DSH_BACKUPS\backup-dsh.ps1` напрямую из Harness.
- Не переписывать сценарий и не создавать другой механизм копирования.
- Не удалять и не изменять файлы в `C:\Users\Andrew\.dsh`.
- Backup script сам поддерживает максимум 7 backup-каталогов в `D:\DSH_BACKUPS\snapshots`.
- В лимит 7 входят и завершённые каталоги `yyyy-MM-dd_HHmm`, и каталоги `yyyy-MM-dd_HHmm.partial`.
- Скрипт может удалять только самые старые backup-каталоги указанного формата внутри `D:\DSH_BACKUPS\snapshots`, чтобы освободить место для новой копии.
- Не использовать `/MIR` или `/PURGE`.
- После запуска сообщить, что задача передана планировщику; результат завершения проверять по состоянию задачи и появившемуся snapshot.
- При ошибке запуска сообщить её и не объявлять резервную копию успешной.

Расписание задачи настраивается отдельно: один автоматический запуск раз в 3 дня в 08:00.
