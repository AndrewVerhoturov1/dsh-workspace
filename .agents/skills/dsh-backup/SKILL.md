# Резервная копия DSH

При явной просьбе пользователя создать или запустить «бэкап» выполнить существующий безопасный сценарий.

Один пользовательский запрос — один запуск сценария. Перед запуском проверить, что `D:\DSH_BACKUPS\backup-dsh.ps1` существует. Если файл отсутствует — ничего не создавать и не пытаться воспроизвести резервное копирование самостоятельно; сообщить ошибку.

Использовать только этот вызов, без видимого окна терминала:

```powershell
& powershell.exe -NoLogo -NoProfile -NonInteractive -ExecutionPolicy Bypass -WindowStyle Hidden -File 'D:\DSH_BACKUPS\backup-dsh.ps1'
```

- Не переписывать сценарий и не создавать другой механизм копирования.
- Не удалять и не изменять файлы в `C:\Users\Andrew\.dsh`.
- Не использовать зеркалирование, очистку, удаление, сжатие, хеши или ротацию.
- После завершения сообщить путь нового снимка и краткий результат.
- При ошибке сообщить её и не объявлять резервную копию успешной.

Планировщик и расписание не менять: они уже настроены отдельно.
