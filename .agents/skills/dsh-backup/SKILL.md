# Резервная копия DSH

При явной просьбе пользователя создать или запустить «бэкап» выполнить существующую задачу планировщика.

Один пользовательский запрос — один запуск задачи. Перед запуском проверить наличие задачи `DSH Backup`. Если задача отсутствует — ничего не создавать и не запускать сценарий напрямую; сообщить ошибку.

Запустить задачу ровно один раз штатным средством Task Scheduler, без ожидания завершения длительного копирования в Harness и без видимого окна терминала:

```powershell
Start-ScheduledTask -TaskName 'DSH Backup'
```

- Не запускать `D:\DSH_BACKUPS\backup-dsh.ps1` напрямую.
- Не переписывать сценарий и не создавать другой механизм копирования.
- Не удалять и не изменять файлы в `C:\Users\Andrew\.dsh`.
- Не использовать зеркалирование, очистку, удаление, сжатие, хеши или ротацию.
- После запуска сообщить, что задача передана планировщику; результат завершения проверять по состоянию задачи и снимку.
- При ошибке запуска сообщить её и не объявлять резервную копию успешной.

Планировщик и расписание не менять: они уже настроены отдельно.
