# Резервная копия DSH

При просьбе пользователя «бэкап» выполнить существующий безопасный сценарий:

- Запустить без видимого окна терминала: `D:\DSH_BACKUPS\backup-dsh.ps1`.
- Не переписывать сценарий и не создавать другой механизм копирования.
- Не удалять и не изменять файлы в `C:\Users\Andrew\.dsh`.
- Не использовать зеркалирование, очистку, удаление, сжатие, хеши или ротацию.
- После завершения сообщить путь нового снимка и краткий результат.
- При ошибке сообщить её и не объявлять резервную копию успешной.

Запускать сценарий через скрытый PowerShell без показа окна пользователю. Планировщик и расписание не менять: они уже настроены отдельно.
