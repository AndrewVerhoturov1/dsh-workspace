## User intent

Проведи исследование только официальных актуальных источников: как правильно считать расход токенов и денежную стоимость в агентной среде (DeepSeek Harness), если человек хочет статистику по одной сессии, одному агенту и всей команде дочерних агентов. Код и implementation ZIP не нужны.
Пользователь хочет видеть: стоимость по опубликованным API-тарифам, количество вызовов модели, входящие токены, reasoning/размышления, кэш (read/write где применимо), исходящие токены; понимать, что конкретно расходует токены. В окружении используются DeepSeek и подключения OpenAI/Codex, но конкретные тарифы/модель/account billing неизвестны; не предполагай API-оплату там, где возможна подписка.
Нужно: 1) по официальным docs DeepSeek/OpenAI (и кратко Anthropic как важному примеру cache write/read) выяснить какие usage-поля сообщаются, reasoning является частью output или отдельным оплачиваемым типом, cached input частью input, различия total vs noncached; 2) объяснить формулу без двойного счёта, отдельно reported token facts, API-price estimate, actual charged money/подписка; 3) отличить текущий размер контекста от накопленного расхода, повторяющийся history/tool output от токенов однократного сообщения; 4) осмысленный request count (model requests vs turns/tools/retries, missing usage on failures) и объединение team с запретом повторно учитывать rollups; 5) официальные ссылки, даты/ограничения точности и небольшой пример расчёта на явно оговорённых тарифах; 6) краткая минимальная концепция интерфейса с разрезами session/agent/team/model и что принципиально нельзя точно вывести только из суммарного usage.
Не делай утверждений о конкретном исходном коде DSH, локальные source facts проверяет отдельный исследователь. Не требуются сторонние billing SaaS, новая инфраструктура, implementation или секреты. Можно рекомендовать сначала использовать встроенную usage-информацию и metadata provider/model/session/parent, отделив неизвестные поля от нуля. Дай практичный ответ по-русски с проверяемыми официальными источниками, не маркетинговую статью. Если официальные pricing/модель изменчивы, укажи дату исследования и не выдавай GPT-6*/Codex internal routing label за достоверный публичный API SKU. Не угадывай цены.
